LeanCore Studio: Simplificando la complejidad financiera a través del diseño

  • UI
  • Prototype
  • Landing Page
  • Design System

El reto fue transformar procesos financieros altamente técnicos y abstractos en un sistema de automatización intuitivo. Mi rol como diseñador UX/UI fue diseñar una interfaz que no solo operara con precisión, sino que generara la confianza necesaria para que el usuario automatice sus decisiones financieras.

2026Lanzado por LeanCore

El desafío

UX para la complejidad financiera

  • La gestión de la carga cognitiva: La automatización fintech suele ser abrumadora. La decisión estratégica más difícil fue ocultar la complejidad del 'backend' bajo una capa de control sencilla, permitiendo al usuario configurar flujos de trabajo complejos sin necesidad de conocimientos técnicos.
  • Diseño basado en la predictibilidad: Cada flujo de automatización se diseñó para que el usuario siempre mantenga el control. Se validó la lógica de la interfaz para asegurar que el sistema sea predecible, reduciendo la incertidumbre ante operaciones automatizadas.

Sistema de diseño

Orden, jerarquía y confianza

En una plataforma fintech, la interfaz es sinónimo de seguridad. Creé un sistema de componentes estrictamente ordenado, siguiendo la nomenclatura exacta de los nodos que definí para garantizar la escalabilidad técnica.

La reutilización de componentes para los flujos de datos asegura que la experiencia del usuario sea consistente, independientemente de qué tan compleja sea la regla de automatización que esté creando.

Handoff

Cuando el diseño habla el lenguaje de los datos

La arquitectura de este sistema fintech requirió una coordinación técnica impecable entre diseño y desarrollo.

  • Nomenclatura precisa: Toda la documentación del diseño respeta los nombres de nodos exactos para evitar errores de implementación en el backend.
  • Especificación de estados: Definí visualmente cómo debe comportarse el sistema ante errores de procesamiento, garantizando que el usuario siempre reciba un feedback claro y seguro.

Impacto

Impacto de negocio: Eficiencia y escalabilidad

  • Control: Autonomía total del usuario para gestionar reglas financieras complejas sin asistencia técnica.
  • Escalabilidad: Un sistema de diseño que soporta la adición constante de nuevos nodos y reglas.
  • Confianza: Interfaz diseñada para minimizar el error humano en la automatización de transacciones.

Reflexión

Este proyecto reforzó mi visión: un diseñador UI/UX en fintech no solo diseña pantallas, diseña la confianza con la que un usuario confía sus finanzas a un sistema automatizado. El seniority se demuestra al entregar un producto que es técnicamente robusto y humanamente comprensible.
